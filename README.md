# Cryptocurrency Price Visualizations

A dashboard for tracking current cryptocurrency prices, selecting coins, and viewing historical price charts across different time intervals. Built with React, JavaScript, Highcharts, styled-components, and the CryptoCompare API.

## Environment Variables

No environment variables are required to run the application.

## Development

Install:

```bash
npm install
```

Start the dev server:

```bash
npm start
```

## Build

```bash
npm run build
```
